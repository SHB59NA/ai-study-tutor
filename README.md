# AI Study Tutor

> Status: 🚧 In Development

AI Study Tutor is an AI-powered study assistant designed to help students interact with their own learning materials.

The project uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from uploaded documents and generate answers grounded in the source material.

A major focus of the project is improving citation accuracy, answer grounding, and retrieval quality.

## Project Goals

- Answer questions using uploaded study materials
- Retrieve relevant document sections before generating responses
- Provide source-grounded answers with citations
- Reduce unsupported or hallucinated responses
- Evaluate retrieval and citation quality
- Improve the system iteratively through testing

## Current Development

The current version focuses on:

- Document ingestion and processing
- Retrieval-Augmented Generation (RAG)
- LLM-based question answering
- Source citation generation
- Grounding evaluation
- Retrieval and response-quality testing

The system is actively being improved, particularly in citation coverage and source-grounding performance.

## Technologies

- Python
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Document Retrieval
- Vector Search / Embeddings
- Prompt Engineering
- AI Evaluation

## Development Approach

The project follows an iterative development process:

1. Process study documents
2. Retrieve relevant context
3. Generate an answer using an LLM
4. Attach supporting citations
5. Evaluate grounding and citation quality
6. Identify failures
7. Improve retrieval and generation
8. Re-test the system
