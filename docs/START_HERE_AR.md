# ابدئي من هنا — AI Study Tutor

هذه نسخة قابلة للتجربة من المشروع، وليست خدمة منشورة للعامة أو نظاماً تعليمياً معتمداً. يمكن تجربة تحميل الملف والبحث وعرض صفحات المصدر دون مفتاح API. توليد الشرح والاختبارات وتصحيح الإجابات يحتاج Gemini مُعدّاً على جهاز التشغيل.

## 1. تشغيل المشروع على Windows

ثبّتي Python 3.11 مع Python Launcher، ثم نزّلي المستودع من GitHub عبر **Code → Download ZIP**، وفكّي الضغط. افتحي PowerShell داخل مجلد المشروع الذي يحتوي `app.py` و`requirements.txt`، ثم نفّذي:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

استخدام مسار Python مباشرة لا يحتاج تغيير سياسة PowerShell لتفعيل البيئة. يحتاج تثبيت الحزم أول مرة إلى اتصال بالإنترنت. بعد تشغيل التطبيق افتحي:

http://127.0.0.1:7860

هذا عنوان محلي على جهازك، وليس رابطاً عاماً لإرساله إلى الجامعة. أوقفي البرنامج بـ `Ctrl+C`. لإعادة التشغيل لاحقاً يكفي الأمر الأخير، ما لم تتغير المتطلبات.

على macOS/Linux، خطوات إنشاء البيئة وتشغيلها موجودة في [README](../README.md).

## 2. تجربة أولى مدتها خمس دقائق، دون Gemini

1. اتركي اللغة **English** لهذه التجربة لأن الدليل المرفق إنجليزي.
2. في تبويب **Upload** اضغطي **Use fictional sample / جرب المثال**. انتظري ظهور **Example ready**.
3. افتحي **Ask Tutor** واتركي **Enable Gemini** غير مفعّل.
4. اكتبي `What does a primary key identify?` واضغطي **Ask tutor / اسأل**.
5. افتحي **View source evidence / عرض المصدر**. ستجدين المقطع الأصلي ورقم صفحته. هذه مقاطع مسترجعة، وليست إجابة أنشأها نموذج لغوي.
6. جرّبي سؤالاً بعيداً عن الدليل. عدم وجود دليل مناسب يجب أن يظهر بدلاً من اختلاق إجابة.
7. اضغطي **Clear my session / حذف مستندي وتقدمي** قبل الانتهاء.

لا تستخدمي كشف درجاتك أو مستندات الطلاب أو ملفات العمل السرية في العرض. المثال المرفق خيالي ومخصص للتجربة.

## 3. تجربة Gemini اختيارية

انسخي `.env.example` إلى ملف جديد اسمه `.env` محلياً، وضعي مفتاحك في `GEMINI_API_KEY`، ثم أعيدي تشغيل التطبيق وفعّلي **Enable Gemini**. لا ترفعي `.env` إلى GitHub ولا ترسلي المفتاح في محادثة أو لقطة شاشة.

مع التفعيل، يُرسل السؤال والمقاطع المسترجعة إلى Google. إنشاء الاختبار وتصحيح الإجابة يستخدمان Gemini أيضاً؛ توجد ملاحظة بهذا داخل تبويب الاختبار. عند تعذر الخدمة يظهر fallback واضح، ولا يُعد ذلك نجاحاً في توليد الإجابة. اختيار العربية لا يحوّل البحث اللفظي إلى بحث متعدد اللغات: السؤال العربي عن ملف إنجليزي يحتاج ترجمة الاستعلام عبر Gemini، أو اطرحي السؤال باللغة نفسها الموجودة في المصدر.

**لم يُختبر اتصال Gemini الحقيقي في التحقق الموثق أدناه؛ لا تدّعي أن جودته أو دقته قد تم التحقق منهما.**

## 5. تجهيز شرحك للجامعة

اقرئي [دليل فهم المشروع وأسئلة المقابلة](OWNER_GUIDE_AR.md)، ثم [وصف المشروع في البورتفوليو](PORTFOLIO.md). قبل اعتماد نص CV، نفّذي التجربة ودوّني إجاباتك عن هذه الأسئلة:

- ما المشكلة التعليمية التي أردت حلها؟
- ما الذي صممتِه أو جربتِه أو عدلتِه بنفسك، وما الذي ساعدت فيه أدوات AI؟
- لماذا نستخدم TF-IDF، وما الفرق بينه وبين neural embeddings؟
- لماذا وجود صفحة مصدر لا يثبت وحده صحة كل ادعاء؟
- ما مثال فشل حقيقي؟ وكيف ستقيّمين التحسينات على أسئلة جديدة؟

التنفيذ الحالي **TF-IDF + Gemini اختياري**؛ لا يستخدم LangChain أو neural embeddings أو قاعدة بيانات متجهات. بيانات الجلسات مؤقتة، ولا توجد حسابات مستخدمين دائمة. مراجعة المزايا والقيود الدقيقة موجودة في [البنية](../ARCHITECTURE.md) و[التقييم](EVALUATION.md) و[الأمان](SECURITY.md).

## 6. حدود التسليم

الكود والتعليمات والاختبارات داخل GitHub. النشر العام، إعداد مفتاح Gemini، الاختبار الحي للمزود، الموافقة على ترخيص إعادة استخدام الكود، والتحقق التعليمي المستقل ليست خطوات تم إنجازها ضمن هذه النسخة. لا تنشريه للعامة ببيانات حقيقية دون مراجعة متطلبات الأمان والنشر. بقاء بعض القيود لا يمنع عرض المشروع كنموذج أولي مع شرح صادق لنطاقه.
